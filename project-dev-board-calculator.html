Assembly Development Board Calculator

A calculator capable of addition, subtraction, multiplication, integer division, and finding the missing side of a right triangle given two sides.

I developed a calculator in 8051 assembly for a MAX10-based development board, using a 4×4 keypad for input and seven-segment displays for output. This project combined low-level hardware interaction, numerical computation, and input validation to provide an interactive calculator.

The program supports addition, subtraction, multiplication, and integer division, along with calculations for finding the hypotenuse or a missing side of a right triangle. It used a 32-bit arithmetic library and an iterative integer square-root routine to perform these calculations.

The key features were:

  • Keypad scanning and software debouncing
  • Binary-coded decimal input and conversion routines for numerical processing and display
  • Digit correction and a display mode for viewing the upper digits of larger numbers
  • An LED indicator for negative subtraction results
  • Checks for out-of-range inputs, arithmetic overflow, division by zero, and invalid triangle inputs

I organized the program into reusable macros and subroutines for input handling, display control, calculations, and error recovery.
