Movie Recommender

A Python tool that recommends movies based on a movie selected by the user.

View project on GitHub

Motivation

As someone who loves to watch movies in my free time, I frequently find myself struggling to decide what to watch. To solve this problem, I wanted to create a tool that could recommend a movie depending on what I felt like watching. I was inspired by Letterboxd, a social network that allows users to log and rate movies. One of Letterboxd's best-known features allows users to decorate their profile by providing their top four movies. I decided to extend this concept by asking "If I can provide my four favourite movies (or just several movies that have elements that I like), can I make a tool that can find me something new to watch?"

Approach

After researching several film databases, I decided to use The Movie Database (TMDB) for this project. TMBD stores data on films, including genres, cast and crew, and keywords, alongside integer ids. Ids are helpful in this case for several reasons, including ensuring distinction between similar movie elements (I would like to avoid recommending the horror movie "Frozen" to people who enjoyed the Disney movie "Frozen"). The movie recommender tool uses the TMDB API to request movies based on user input, store their data in a custom class, and use this data to request again and find similar movies. From there, overall similarity scores between each candidate movie and the input movies are calculated, and the tool returns the movies it found with the highest similarity.

Use

To use the tool, a user enters the title of a movie that they would like their recommendations to be related to. They then adjust the weights related to genre, keywords/key ideas, cast, and director. This allows the user to decide whether the recommended movies should share ideas, actors, or genre with the input movie, and the balance of these parameters. From there, the tool searches TMDB for movies that share parameters with the input movie. These results are processed, and the unique id for each parameter in each candidate movie is found. The set of ids associated with each parameter are compared between the input movie and each candidate using the Jaccard index:

\[ J(A, B) = \frac{|A \cap B|}{|A \cup B|} \]

Each index is multiplied by the corresponding weight set by the user, and we can sum these results to get an overall similarity score between the input movie and each candidate. Finally, the candidates with the highest scores are returned as the tool’s official recommendation.
